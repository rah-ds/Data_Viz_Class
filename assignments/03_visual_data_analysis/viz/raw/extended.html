Wikipedia Arbitration — Extended Visual Analyses

Three additional visualization techniques applied to the same 481 ArbCom case dataset: a directed acyclic graph, a beeswarm census, and a radial recurrence chart.

← Original three (Sankey, Treemap, Heatmap) Experimental three (Parallel, Unit, Sunburst) →

Visualization 4: The Dispute Resolution DAG

A directed acyclic graph showing every valid escalation pathway, with node size encoding throughput and edge thickness encoding flow volume

Unlike the Sankey (which compresses the system into horizontal bands), the DAG preserves the network topology — you can see that Third Opinion and Request for Comment sit at the same authority level, that DRN can feed both ANI and ArbCom, and that Talk Page can short-circuit directly to ANI for conduct violations. Edge arrows show directionality; node radius encodes total throughput. Hover for stage descriptions.

Visualization 5: A Census of Every Case

Each of 481 ArbCom cases rendered as an individual dot — organized by category, colored by dispute type, sized by recurrence depth

This is the only visualization in our set that shows every individual case. The treemap and heatmap aggregated; the beeswarm disaggregates. Larger dots are repeat offenders (cases that returned to ArbCom multiple times). The sheer number of gray dots in "Editor Disputes" gives visceral weight to the finding that ArbCom is a conduct court. Hover any dot for the case name.

Visualization 6: The Disputes That Won't Die

A radial burst showing the 33 recurring case families — disputes that returned to ArbCom for a sequel — arranged by category with spoke length encoding recurrence depth

Each spoke radiates from a central hub, representing one case family (e.g., "Rex071404" → 4 ArbCom hearings). Spoke length encodes the number of sequels; dots along each spoke mark individual hearings. The radial layout groups families by category sector, revealing that Editor Disputes dominate recurrence but Geopolitics produces the most deeply recurrent topic-level disputes (Palestine-Israel articles reached case #5). These are the failures of finality — where even ArbCom's binding authority could not permanently resolve the conflict.
