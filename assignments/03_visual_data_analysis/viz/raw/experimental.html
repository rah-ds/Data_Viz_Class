Wikipedia Arbitration — Experimental Visualizations

Three more techniques — parallel coordinates, unit chart, and sunburst — applied to the same 481 ArbCom cases. Each uses a fundamentally different spatial logic.

← Original three (Sankey, Treemap, Heatmap) ← Extended three (DAG, Beeswarm, Radial)

Visualization 7: Multivariate Threads

A parallel coordinates plot — each of 481 cases is a polyline threading through four attribute axes, revealing which attribute combinations cluster together

Every line is one ArbCom case, threading from Category → Dispute Type → Complexity → Recurrence. Thick bundles of lines between axis values reveal dominant attribute pathways. The near-total dominance of the Editor Disputes → Conduct → Simple → 1 bundle is immediately visible — but so are the thinner, more interesting threads like Geopolitics → Content → Very Complex → 5. Brush any axis to filter. This is the only technique that shows four dimensions simultaneously without aggregation.

Visualization 8: Counting Every Case

A unit chart — one small square per case, grouped by category and colored by dispute type. No aggregation, no abstraction: 481 squares = 481 cases.

This is the most Tufte-esque visualization in the set: maximum data-ink ratio, zero chartjunk, no aggregation. Each square is a case. The 309 orange squares in the Editor Disputes block dwarf the other categories in a way that no bar chart or percentage could match — you see the imbalance by counting. Recurring cases are marked with a dot. Hover for case names.

Visualization 9: Drilling Into the Hierarchy

A sunburst diagram — three concentric rings mapping Category → Dispute Type → Complexity, with arc length proportional to case count. Click to zoom.

Click a ring segment to zoom in

The sunburst combines the treemap's part-to-whole encoding with a radial layout that naturally suggests hierarchy — inner rings are higher-level groupings, outer rings are finer detail. Clicking a segment zooms in, re-proportioning the arcs so that small categories become readable. This is the only visualization that lets you smoothly transition between overview and detail without losing spatial context.
