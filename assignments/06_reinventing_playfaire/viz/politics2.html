Visualizing Wikipedia's Arbitration Boundaries
How to read this chart ›
One row = one case
Each row is a single Wikipedia arbitration case, sorted by start date within each group.
60 segments = full timeline
The row is sliced into 60 equal windows of the case's total lifespan. Each cell is colored by the dominant editing phase in that window.
Spark strip ▲ ▼
Green up = editors joining that segment. Red down = editors making their last edit.
Hatched tail ░░░
Diagonal-hatched cells after the last active segment — the case resolved before the timeline ran out.
Duration pill ⏱
Orange ⏱ = ran longer than 1.5× the group median. The amber-shaded bar region shows time past the typical endpoint. Hover to see why.
Case label ›
Click any case name to reveal the ArbCom decision summary inline. Click again to collapse.
